# 《我能看见风险》项目包

## 定位

原创男频都市异能爽文，吸收早期校园都市异能作品的类型引擎：低位男主、实用异能、校园打脸、赚钱翻身、城市灰色地图、暧昧关系线和隐秘组织扩张。

本项目不复用任何既有小说的人名、能力名、剧情事件、学校、城市或标志性桥段。

## 当前交付

- `bible.md`：小说正典设定、角色、能力、势力、卷结构。
- `outline-first-30.md`：前 30 章留存节奏和每章爽点。
- `chapters/001.md` 到 `chapters/165.md`：前 165 章正文，已推进到青石旧铺契二层夹、NO-EYE-BAY-03 无照封存格三号、QSP-BASE-CUT-03 托纸纸源，以及 NO-LAMP-RETURN-7 无灯回执柜七号。
- `ledgers/`：事实、能力、关系、承诺、势力和时间线账本。
- `upload/fanqie-upload-package.md`：番茄小说创建作品前准备材料。

## 续写原则

1. 每章必须有一个明确读者奖励：打脸、识破、护美、赚钱、暧昧、升级、代价。
2. 前 10 章必须完成一次公开打脸和一次关系转向。
3. 前 30 章必须打开赚钱地图和城市地图，但不能过早解释透终局组织。
4. 能力只能提供信息优势，不能替主角解决一切。
5. 女角色必须绑定剧情地图，有目标、有筹码、有行动。
